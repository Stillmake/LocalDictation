# LocalDictation

On-device speech-to-text for macOS.

## Install

1. Install the app with `brew install --cask stillmake/tap/localdictation`, or from [Stillmake/releases](https://github.com/Stillmake/releases/releases?q=localdictation).
2. Download the model:

   ```sh
   curl -fsSL https://raw.githubusercontent.com/Stillmake/LocalDictation/main/download-model.sh | zsh
   ```

The app finds the model on its own.
