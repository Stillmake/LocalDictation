# LocalDictation

On-device speech-to-text for macOS.

## Install

1. Install the app from the [latest release](https://github.com/Stillmake/LocalDictation/releases/latest).
2. Download the model:

   ```sh
   curl -fsSL https://raw.githubusercontent.com/Stillmake/LocalDictation/main/update-model.sh | zsh
   ```

3. In the app, choose `~/.local/share/LocalDictation/Qwen3-ASR-0.6B-8bit`.
